# راهنمای فارسی ECC (Everything Claude Code)

این پوشه حاوی راهنمای کامل قابلیت‌های نصب‌شدهٔ ECC روی OpenCode به زبان فارسی است.

## فایل PDF

**`ECC-Capabilities-FA.pdf`** — سند کامل همهٔ agents، commands، skills، tools، plugins، hooks و MCP servers نصب‌شده از ECC روی OpenCode با توضیحات فارسی و روش استفاده.

هر کس که راهنمای این ریپازیتوری را به زبان پارسی نیاز دارد می‌تواند این فایل را دانلود کند.

### محتوای PDF

- **Agents: ۲۶** — زیر-عامل‌های تخصصی (planner، code-reviewer، tdd-guide، security-reviewer و…)
- **Commands: ۳۵** — دستورات slash ECC (/plan، /tdd، /code-review، /verify و…)
- **Skills: ۳۵۴** — مهارت‌های بارگذاری‌شده با توضیحات فارسی کامل
- **Tools: ۹** — ابزارهای سفارشی OpenCode (run-tests، security-audit، check-coverage و…)
- **Plugins: ۴** — پلاگین‌های TypeScript
- **Hooks: ۲۷** — در ۸ گروه رویداد (PreToolUse، PostToolUse، Stop و…)
- **MCP Servers: ۳۴** — تعریف‌شده در mcp-servers.json

### نسخه

- ECC 2.2.3 (منبع: affaan-m/ECC، fork: javadhamed/ECC)
- تاریخ تولید: 2026-10-20

### استفاده

فایل PDF را دانلود کرده و با هر PDF reader باز کنید. متن فارسی با جهت راست به چپ (RTL) نمایش داده می‌شود.
